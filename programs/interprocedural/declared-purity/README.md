# declared-purity

believing a const or pure promise on a callee in another file. Part of the interprocedural phase of the M4 plan.

32 programs. Each row gives the axis point the program was generated for and the output it must produce. A compiler that prints anything else has a bug, whatever optimization level it was asked for.

These programs are more than one translation unit each. The other units are listed beside the one that has `main` in it, and they are all handed to the compiler on one command line, in that order.
